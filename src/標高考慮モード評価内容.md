# 標高考慮モード 雲量計算および評価仕様

本ドキュメントは、Stargazer2 における「標高を考慮した場合の雲量計算」の判定要素、適用条件、計算ロジック、および評価基準をまとめたものです。

---

## 1. 標高考慮モードの概要一覧表

| 項目 | 内容・基準 | 詳細・備考 |
| :--- | :--- | :--- |
| **適用条件** | **標高 1,500m 以上** (`loc.elevation >= 1500`) | 1,500m 未満の地点は標高を考慮せず通常の「総雲量」を使用 |
| **対象気象要素** | **中層雲量** (`cloud_cover_mid` [%])<br>**高層雲量** (`cloud_cover_high` [%])<br>**総雲量** (`cloud_cover` [%]) | **低層雲 (`cloud_cover_low`) は除外**。<br>（標高1,500m以上では観測地より下層＝雲海となり、上空視界に影響しにくいため） |
| **合成雲量の計算式** | $\text{aloft} = 100 \times \left(1 - \left(1 - \frac{\text{mid}}{100}\right) \times \left(1 - \frac{\text{high}}{100}\right)\right)$ | 中層雲と高層雲がランダムに重なり合う確率モデル（ランダム重なり近似） |
| **総雲量によるキャップ** | $\text{elevation\_val} = \min(\text{aloft},\; \text{総雲量})$ | API提供元の総雲量を超えないよう上限クリップ（最終的に四捨五入して整数表示） |

---

## 2. 状態判定（背景色）の評価基準一覧表

標高考慮モード時のセル背景色判定は、**上空合成雲量**だけでなく、薄雲・巻雲として星空観測に影響しやすい**高層雲量単体**も基準として判定されます。

| 状態（ステータス） | 表示色 | 判定基準（いずれかを満たす場合） |
| :--- | :--- | :--- |
| **不可 (Poor)** | グレー (`#64748b`) | **上空合成雲量 $\ge 50\%$** または **高層雲量 $\ge 50\%$** |
| **可 (Fair)** | イエロー (`#c8b13c`) | **上空合成雲量 $\ge 30\%$** または **高層雲量 $\ge 30\%$**（かつ不可でないこと） |
| **良 (Good)** | スカイブルー (`#38bdf8`) | **上空合成雲量 $< 30\%$** かつ **高層雲量 $< 30\%$** |

---

## 3. 通常地点（標高 1,500m 未満）との比較

| 区分 | 評価対象 | 良 (Good: 青) | 可 (Fair: 黄) | 不可 (Poor: 灰) |
| :--- | :--- | :---: | :---: | :---: |
| **通常地点 (< 1500m)** | 総雲量 (`cloud_cover`) | $< 30\%$ | $30\% \sim 49\%$ | $\ge 50\%$ |
| **高標高地点 ($\ge 1500m$)** | 上空合成雲量 + 高層雲量 | 双方 $< 30\%$ | いずれか $30\% \sim 49\%$ | いずれか $\ge 50\%$ |

---

## 4. 関連する警告要素（セル内併記）

セル内には雲量のほか、以下の気象要素に基づく警告が併記されます。

| 要素 | 警告条件 | 表示内容 |
| :--- | :--- | :--- |
| **風速警告** | 地上10m風速 $\ge 5.0\,\mathrm{m/s}$ | 風速の整数値（赤字表示） |
| **霧・結露判定** | **高**: 露点差 $\le 1.0^\circ\mathrm{C}$ かつ 湿度 $\ge 95\%$ かつ 風速 $\le 2.0\,\mathrm{m/s}$<br>**中**: 露点差 $\le 2.0^\circ\mathrm{C}$ かつ 湿度 $\ge 90\%$ かつ 風速 $\le 3.0\,\mathrm{m/s}$<br>**露**: 露点差 $\le 3.0^\circ\mathrm{C}$ または 湿度 $\ge 85\%$ | 「高」「中」「露」（赤字表示） |
